经历概述

打通波形生成、自定义串口协议、CRC16 校验、数据回传与 Python GUI 可视化的完整链路。

系统由 AT32F403A 下位机与 Python 上位机组成。上位机配置参数并通过 USART 发送自定义协议指令；下位机在中断中接收数据，依据帧头、帧尾与 CRC16 校验指令完整性和准确性，再按参数生成波形并回传采样数据。

上位机解析串口数据后通过 GUI 展示波形。通信层采用环形缓冲区、指令帧校验、CRC16 与参数校验的双重保护；性能层采用下位机中断接收与定时发送、上位机子线程串口通信和 Matplotlib 局部重绘，避免界面卡顿。

该项目将硬件底层、通信协议、软件 UI 和数据可视化解耦，形成职责清晰、便于调试和扩展的全链路实现。
